# 🚀 100 Days of Coding

A 100-day journey focused on **Data Structures & Algorithms**, problem-solving, and building consistency in coding.

### 🎯 Goal

- Solve DSA problems every day
- Strengthen problem-solving skills
- Learn optimized approaches
- Prepare for technical interviews & placements
- Maintain consistency and track progress

### 📚 Topics

`Arrays` · `Strings` · `Hashing` · `Binary Search` · `Linked List` · `Stack` · `Queue` · `Trees` · `Heap` · `Graphs` · `Greedy` · `Backtracking` · `Dynamic Programming`

### 💻 Platforms

- LeetCode
- GeeksforGeeks
- Other coding challenges


> **Consistency over perfection. One problem, one day, one step closer to the goal. 🚀**
